# 合同体检 Demo — 验收清单

> 本清单按优先级排列，前 9 项为"可 Demo"的硬性门槛。

## 核心流程（必须全部通过）

- [ ] 1. `GET http://localhost:3001/health` 返回 200
- [ ] 2. 前端首页 `http://localhost:5173` 可正常打开
- [ ] 3. 空文本提交时前端有明确提示，或后端返回 `INVALID_INPUT`
- [ ] 4. 点击主 Demo 示例后内容正常填入并可提交
- [ ] 5. Loading 状态可见，且提交按钮不会重复触发
- [ ] 6. 结果页显示总体风险等级、风险数量和 4～6 个核心风险
- [ ] 7. 每个风险卡片包含：原文、人话解释、修改建议
- [ ] 8. 检查清单（Checklist）和免责声明（Disclaimer）可见
- [ ] 9. 后端服务停止后，前端显示错误提示而非白屏

## 降级与边界（必须全部通过）

- [ ] 10. 开启 `DEMO_FALLBACK=true` 时，页面明确标识 `demo_fallback`
- [ ] 11. 输入超过 50,000 字符时返回 `TEXT_TOO_LONG`，不调用 AI
- [ ] 12. AI 超时（>25s）时返回 `AI_TIMEOUT`，不暴露内部堆栈
- [ ] 13. AI 返回非 JSON 或缺少字段时返回 `AI_INVALID_RESPONSE`

## 构建与部署

- [ ] 14. 前端生产构建 `npm run build` 通过，无类型错误
- [ ] 15. 后端测试或最少 curl 冒烟测试通过
- [ ] 16. Git 仓库中不存在 `.env`、密钥或 `node_modules`

## 演示准备

- [ ] 17. 主 Demo 合同完整演练 2 次，25 秒内稳定返回
- [ ] 18. 备用合同（劳动/用户协议）演练 1 次
- [ ] 19. P0 缺陷清零，P1 经员工 1 明确接受或修复
- [ ] 20. Demo 讲稿熟悉，讲解顺序：输入 → 等待 → 结果重点 → 免责声明
